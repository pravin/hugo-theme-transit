# Hugo Theme Transit

A blog theme that draws your archive as a transit map. **Every tag is a line, every post is a station**, and posts that share tags become interchanges. Readers can see at a glance what you write about, how topics connect, and how your writing has changed over the years.

![Transit, light mode](https://raw.githubusercontent.com/pravin/hugo-theme-transit/main/images/screenshot.png)

![Transit, dark mode](https://raw.githubusercontent.com/pravin/hugo-theme-transit/main/images/screenshot-dark.png)

## What makes it different

* **A map made from your content.** The home page map is generated by Hugo at build time from your tags and dates. There is nothing to draw or maintain. Lines are your busiest tags, stations sit left to right by date, and year markers turn the map into a timeline.
* **"You are here" on every article.** For each of a post's tags, a strip shows the previous (older) and next (newer) post on that line. It is related-posts navigation where the reader can see *why* two posts are related, and ride one topic from start to finish.
* **Lines have their own pages.** Each tag page draws its line top to bottom, with interchange bullets showing where each station connects to other lines. The tags page shows every line as a card.
* **Small and fast.** One hand-written stylesheet, a few lines of JavaScript for the light/dark toggle, and an inline SVG map. No CSS framework, no icon font.

## Installation

The theme needs Hugo v0.146.0 or later.

As a Git submodule,

```sh
git submodule add https://github.com/pravin/hugo-theme-transit.git themes/hugo-theme-transit
```

then set `theme = "hugo-theme-transit"` in your site's `hugo.toml`.

Or as a Hugo module,

```sh
hugo mod init github.com/you/your-site
```

```toml
[module]
  [[module.imports]]
    path = "github.com/pravin/hugo-theme-transit"
```

To try the example site,

```sh
cd exampleSite
hugo server
```

## Configuration

A complete example lives in [`exampleSite/hugo.toml`](https://github.com/pravin/hugo-theme-transit/blob/main/exampleSite/hugo.toml). A minimal config,

```toml
baseURL = "https://example.com/"
title = "Your Name"
theme = "hugo-theme-transit"

[params]
  tagline = "Thoughts on engineering and management"
  author = "Your Name"
  authorImgPath = "/img/author.png"
  authorBlurb = "A line or two about you."
  mainSections = ["posts"]

  [params.social]
    github = "https://github.com/you"
    email = "mailto:you@example.com"

[markup]
  # Lets syntax colours follow light and dark mode
  [markup.highlight]
    noClasses = false
```

### Site parameters

| Parameter | Default | Description |
| --- | --- | --- |
| `tagline` | | Large heading on the home page, and the description used for SEO |
| `author` | | Shown in the about box, article meta and footer |
| `authorImgPath` | | Photo for the about box, also the fallback social preview image |
| `authorBlurb` | | A line or two about you (Markdown allowed) |
| `mainSections` | Hugo's default | Sections whose pages are stations on the map and the home page |
| `defaultTheme` | `"auto"` | `"auto"` follows the visitor's OS; `"light"` or `"dark"` forces one |
| `themeToggle` | `true` | Show the light/dark button in the header |
| `favicon` | | Path to a favicon |
| `social` | | Links shown in the about box and footer. Keys: `mastodon`, `bluesky`, `github`, `twitter`, `linkedin`, `medium`, `facebook`, `email`, plus `twitteruser` for the Twitter card |

### Map parameters

All live under `[params.transit]` and are optional.

| Parameter | Default | Description |
| --- | --- | --- |
| `taxonomy` | `"tags"` | The taxonomy whose terms become lines |
| `maxLines` | `8` | How many lines to draw on the map. The busiest tags win; posts on none of them ride a grey "Other" line |
| `labels` | `12` | How many of the newest stations are named on the map. Labels that would overlap a newer one are skipped. `0` hides names (hover still shows them) |
| `palette` | 10 colours | Line colours, given to the busiest tags in order. Choose colours dark enough to carry white text |
| `colors` | | Pin a colour to a tag, e.g. `golang = "#00796B"` |
| `codes` | | Pin a two-letter bullet code to a tag, e.g. `golang = "GO"`. Otherwise codes come from the tag name, avoiding duplicates |
| `intro` | "Every topic is a line…" | Sentence under the tagline on the home page |
| `otherName` | `"Other topics"` | Name of the grey line for posts not on any drawn line |
| `legendLines` | `12` | How many lines the home page legend lists |
| `conductorLabel` | `"Your conductor"` | Heading of the about box |

```toml
[params.transit]
  maxLines = 8
  labels = 12
  [params.transit.colors]
    markdown = "#C62828"
  [params.transit.codes]
    markdown = "MD"
```

In dark mode, line colours are brightened automatically so they stay clear on the dark background.

### Menu

By default the header shows Map, Stations, Lines and About (if you have an `/about` page), plus RSS. To change them, define a `main` menu,

```toml
[[menus.main]]
  name = "Articles"
  pageRef = "/posts"
  weight = 10
  [menus.main.params]
    # Optional: inlines assets/icons/<name>.svg from your site
    icon = "rocket"
```

### Front matter

| Field | Description |
| --- | --- |
| `tags` | The lines this post is a station on |
| `description` | Shown under the title and in lists |
| `author` | Overrides `params.author` for this post |
| `image` | A page-bundle image used as the social preview |
| `previewimage` | Path or URL of the social preview image |
| `disableComments` | Turn off Disqus on this page |

### Comments and analytics

Set `services.disqus.shortname` to enable comments, and `services.googleAnalytics.ID` for Google Analytics (production builds only).

## Customising

* **Styles.** All colours are CSS variables at the top of `assets/css/transit.css`, written as `light-dark(<light>, <dark>)`. Copy the file to your site's `assets/css/` to override it.
* **Head and footer.** Create `layouts/_partials/custom_header.html` or `custom_footer.html` in your site to add code to `<head>` or before `</body>`.
* **Tips for a clear map.** A few broad tags make long lines with plenty of interchanges. Many one-off tags make short stubs. Rare tags drop off the map but keep their own pages.
